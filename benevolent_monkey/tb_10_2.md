## Nick Description

This is a focusing meditation that helps quiet the mind when it is not too busy.

## Title

Tibetan Bell 2 Minute Intervals

## Description

A 10-minute silent meditation with the Tibetan Singing Bowl marking each two-minute interval.

```

<break time="114.408s"/>
[Tibetan Singing Bowl]

[Tibetan Singing Bowl]
<break time="114.408s"/>
[Tibetan Singing Bowl]
<break time="114.408s"/>
[Double Tibetan Singing Bowl]
```
